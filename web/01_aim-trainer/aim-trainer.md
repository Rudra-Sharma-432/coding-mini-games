
# Aim Trainer

| Property | Details |
|---|---|
| ID | 001 |
| Difficulty | Easy |
| Language | JavaScript |
| Technologies | HTML, CSS, JavaScript |
| Estimated Time | 1 Hour(s) |

## 1. Objective

Build a browser-based Aim Trainer game where users
click targets appearing at random positions.

The game should measure reaction time and display
the player's final performance.

## 2. Functional Requirements

- [ ] Create a game area.
- [ ] Display a circular clickable target.
- [ ] Move the target after every successful click.
- [ ] Keep the target inside the game area.
- [ ] Track successful clicks.
- [ ] Calculate average reaction time.
- [ ] Display the final result.
- [ ] Add a restart option.

## 3. Provided Assets

The assets folder contains:

- `target.png` — PNG version of the target.
- `target.svg` — SVG version of the target.

You can use either image as the clickable target.

Asset paths:
- `assets/target.png`
- `assets/target.svg`

You are allowed to use and modify these assets
for your implementation.

## 4. Concepts to Learn

- DOM Manipulation
- Event Handling
- JavaScript Functions
- Math.random()
- Date.now() / performance.now()
- CSS Positioning

## 5. Constraints

- Use vanilla HTML, CSS and JavaScript.
- Do not use external game engines.
- Do not use JavaScript frameworks.
- Keep the code readable and beginner-friendly.

## 6. Bonus Tasks

- Add a timer.
- Track missed clicks.
- Add different target sizes. (Difficulty: Easy, Medium, Hard)
- Save the best score using localStorage.
